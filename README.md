# Tic-Tac-Toe

A classic two-player tic-tac-toe game for the terminal, built with Node.js.

## Requirements

- Node.js (no external dependencies)

## How to Play

```bash
node index.js
```

1. The board is displayed as a 3×3 grid with positions numbered 1–9:
   ```
    1 | 2 | 3
   ---+---+---
    4 | 5 | 6
   ---+---+---
    7 | 8 | 9
   ```

2. **Player X** goes first. Enter a position number to place your mark.

3. Players alternate turns until someone wins or the board is full.

4. A player wins by completing a **row**, **column**, or **diagonal**.

5. If all 9 cells are filled with no winner, the game is a **draw**.

6. After each game, choose to **play again** or **quit**.
